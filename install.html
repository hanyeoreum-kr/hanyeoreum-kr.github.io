📲 한여름 앱 설치 방법

스토어에서 받을 필요 없어요. 홈 화면에 추가하면 앱처럼 바로 열리고, 새 견적·채팅 알림도 받을 수 있어요.

⚠️ 카카오톡·네이버·인스타그램 앱 안에서 열면 추가가 안 돼요.
오른쪽 아래(또는 위) ⋮ / 공유 버튼 → "다른 브라우저로 열기"를 먼저 눌러 주세요.

🍎 아이폰 (사파리)

1사파리로 hanyeoreum.co.kr 에 들어가요. (크롬·네이버 앱에서는 안 돼요)
2화면 아래 가운데 공유 버튼(네모에 위쪽 화살표 ⬆️)을 눌러요.
3목록을 아래로 내려서 "홈 화면에 추가"를 눌러요. 안 보이면 맨 아래 "작업 편집"에서 추가할 수 있어요.
4오른쪽 위 "추가"를 누르면 홈 화면에 한여름 아이콘이 생겨요.
5홈 화면의 한여름 아이콘으로 열고 로그인 → ☰ 메뉴 → 🔔 알림 켜기 → "허용". 아이폰은 이렇게 설치한 앱에서만 알림이 와요.

🤖 안드로이드 (삼성·LG 등)

1크롬 또는 삼성 인터넷으로 hanyeoreum.co.kr 에 들어가요.
2화면에 "앱 설치" 안내가 뜨면 바로 눌러요. 안 뜨면 오른쪽 위 ⋮ 메뉴(삼성 인터넷은 아래 ≡)를 눌러요.
3"앱 설치" 또는 "홈 화면에 추가"를 누르고 "설치"를 눌러요.
4홈 화면의 한여름 아이콘으로 열고 로그인 → ☰ 메뉴 → 🔔 알림 켜기 → "허용".

알림이 안 와요

  • 기사님은 기사 화면 오른쪽 위가 [영업중]인지 확인해 주세요. 휴무면 새 요청 알림이 오지 않아요.
  • 휴대폰 설정 → 알림에서 한여름(또는 사용하는 브라우저) 알림이 켜져 있는지 확인해 주세요.
  • 아이폰은 iOS 16.4 이상에서 홈 화면에 추가한 앱으로만 알림을 받을 수 있어요.
